카톡모터스 대시보드 개인정보처리방침

시행일: 2026-11-25

「카톡모터스 대시보드」(이하 "앱")는 카톡모터스(Car-Talk Motors) YouTube 채널 운영자가 자신의 채널 수익 현황을 확인하기 위해 직접 사용하는 개인용 도구입니다. 일반 이용자에게 제공되는 서비스가 아닙니다.

1. 접근하는 정보

채널 운영자가 Google 계정으로 승인한 경우에 한해, YouTube Analytics API의 읽기 전용 범위(https://www.googleapis.com/auth/yt-analytics-monetary.readonly)로 본인 채널의 일별 예상 수익(estimatedRevenue, estimatedAdRevenue, estimatedRedPartnerRevenue) 수치를 조회합니다.

2. 정보의 저장과 이용

조회한 수치와 승인 토큰은 운영자 본인의 컴퓨터에만 파일로 저장되며, 대시보드 화면에 수익을 표시하는 목적으로만 사용합니다. 서버로 전송하거나 제3자에게 제공·판매·공유하지 않으며, 광고나 분석 목적으로 사용하지 않습니다.

3. Google API 서비스 이용 정책

이 앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 전달하는 경우는 Limited Use 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

4. 보관 및 삭제

저장된 수치와 토큰은 운영자가 앱 폴더의 파일을 삭제하면 즉시 제거됩니다. 또한 Google 계정 권한 관리에서 언제든지 앱의 접근 권한을 취소할 수 있습니다.

5. 문의

문의는 카톡모터스 YouTube 채널(youtube.com/channel/UColEgX73QmFmGMzZUgpo1bg)을 통해 주시기 바랍니다.

Privacy Policy — Car-Talk Motors Dashboard

Effective: 2026-11-25

This is a personal tool used only by the owner of the Car-Talk Motors YouTube channel to view the channel's own estimated revenue. It is not offered to the public.

Data accessed. With the owner's consent, the app reads daily estimated revenue figures for the owner's own channel through the read-only YouTube Analytics API scope yt-analytics-monetary.readonly.

Use and storage. The figures and the authorization token are stored only as local files on the owner's computer and are used solely to display revenue in the dashboard. They are not transmitted to any server, shared with, sold to, or transferred to third parties, and are not used for advertising.

Google API Services User Data Policy. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion. Deleting the app's local files removes all stored data, and access can be revoked at any time at myaccount.google.com/permissions.

Contact. Via the Car-Talk Motors YouTube channel linked above.
